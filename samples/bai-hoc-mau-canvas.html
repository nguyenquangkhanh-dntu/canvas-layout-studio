Bài học 01 · Lập trình Web API

Web API: khái niệm và kiến trúc cơ bản

Bài này giúp sinh viên hiểu Web API là gì, cách client và server trao đổi dữ liệu qua HTTP, và viết được endpoint đầu tiên bằng ASP.NET Core.

🎯

Mục tiêu học tập

Sau bài học, sinh viên có thể:

  • Trình bày khái niệm Web API và mô hình client - server.

  • Phân biệt các phương thức HTTP: GET, POST, PUT, DELETE.

  • Đọc hiểu một request và response dạng JSON.

1. Web API là gì?

Web API là tập hợp các điểm truy cập (endpoint) cho phép chương trình khác gửi yêu cầu và nhận dữ liệu qua giao thức HTTP.

Thay vì trả về trang HTML cho người dùng, Web API thường trả về dữ liệu JSON để ứng dụng web, mobile hoặc desktop tự hiển thị.

Request · HTTP 
GET /api/books/1 HTTP/1.1
Host: localhost:5000
Accept: application/json
Response · JSON 
{
  "id": 1,
  "title": "Lập trình C# cơ bản",
  "available": true
}

2. Các phương thức HTTP thường dùng

GET

Lấy dữ liệu. Không làm thay đổi trạng thái trên server.

POST

Tạo mới một tài nguyên, dữ liệu gửi trong body.

PUT

Cập nhật toàn bộ một tài nguyên đã có.

DELETE

Xóa một tài nguyên theo định danh.

❗

Phân biệt PUT và PATCH

PUT gửi lại toàn bộ đối tượng; PATCH chỉ gửi các trường cần thay đổi. Dùng sai có thể làm mất dữ liệu của những trường không được gửi.

3. Viết endpoint đầu tiên

Với Minimal API của ASP.NET Core, chỉ cần vài dòng để có một endpoint trả về danh sách sách dạng JSON:

Program.cs · C# 
var builder = WebApplication.CreateBuilder(args);
var app = builder.Build();

var books = new[] { new { Id = 1, Title = "Lập trình C# cơ bản" } };

app.MapGet("/api/books", () => books);

app.Run();
💡

Thử ngay

Chạy lệnh dotnet run, sau đó mở trình duyệt tới http://localhost:5000/api/books để xem kết quả JSON.

✍️

Bài tập

  1. Thêm endpoint GET /api/books/{id} trả về một cuốn sách.

  2. Trả về mã 404 khi không tìm thấy.

  3. Kiểm tra bằng Postman và chụp màn hình kết quả.

❓
